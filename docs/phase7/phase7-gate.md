## Defects found and fixed in this phase
- Embedding failures returned a raw 500 (now 503 `embedding_unavailable`, nothing stored on failed upload).
- A model-claimed asset id not present in the report was not rejected for non-Ollama clients (now rejected, falls back to rules and human review).
- Test pollution: shared service-desk mock counters leaked between tests (fixture now resets per test).
