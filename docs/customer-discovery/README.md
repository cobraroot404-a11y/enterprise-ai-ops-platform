# Customer discovery (fictional)

Both customers in this repository, **Apex Industrial Manufacturing** and **Meridian Fleet Logistics**, are **fictional**. No real customer interviews, site visits, contracts or deployments occurred, and none is claimed. These documents state assumptions so that requirements, tests and demonstrations have a concrete context.

| Customer | Document |
|---|---|
| Apex Industrial Manufacturing | [apex-industrial.md](apex-industrial.md) |
| Meridian Fleet Logistics | [meridian-fleet.md](meridian-fleet.md) |

Each document covers: business background, current workflow, pain points, stakeholders, existing systems, data sources, security constraints, deployment constraints, success criteria, assumptions and open questions (Part 6 of the specification). The requirements-to-solution matrix that maps each major requirement to a customer need, implementation, component, test, acceptance criterion and evidence is [../customer-delivery/02-requirements-to-solution-matrix.md](../customer-delivery/02-requirements-to-solution-matrix.md).
